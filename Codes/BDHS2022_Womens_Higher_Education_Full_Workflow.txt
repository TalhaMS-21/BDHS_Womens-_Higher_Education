*==============================================================================
* BDHS 2022 - WOMEN'S HIGHER EDUCATION
* REPRODUCIBLE WORKFLOW: RAW IR DATA -> VARIABLE CONSTRUCTION -> ANALYSIS -> OUTPUTS
*
* HOW TO RUN
*   1. Edit the $raw and $out paths in Section 0 below.
*   2. Run this entire do-file from the beginning in Stata 17 or later.
*   3. Check the log and recode-validation tables before interpreting results.
*   4. Expected analytic N in the current workflow is approximately 18,794;
*      this is a diagnostic expectation, not a guaranteed result.
*
* IMPORTANT
*   - The raw BDHS dataset is not included in this repository.
*   - Do not upload the restricted/raw BDHS microdata to a public GitHub repo.
*   - Check all source-variable codes against the official BDHS 2022 codebook.
*
* WHAT WAS FIXED (compared with the file that gave 567 women)
*   - partner_occ_cat: the generic ranges (1-3, 4-5, 6-9) matched almost no BDHS
*     codes, so nearly everyone became missing and dropped out of the models.
*     The BDHS code mapping (0/61/62, 11-14, 15-16, 21-23, 31, 41, 51-52, 96) is back.
*   - media_exposure: now grouped (none/low/moderate/high); before it was the raw
*     0-6 score used as a category (levels 1,2,3,4,6; level 6 predicted perfectly).
*   - internet_uses: the 6-level coding is back (V171B 0/1/2/3 = not in month /
*     less than weekly / weekly / almost daily); the new file reversed the
*     frequency order and dropped past users (V171A == 2).
*   - phone_type: owners with unknown smartphone status are counted and kept as basic phone.
*   - first_birth_timing: early birth is any V212 < 18 (not only 12-17).
*   - `clear all` removed (it wiped the data you had opened); duplicate-run check added.
*   - region keeps its division names (clonevar).
*   - CATEGORIES (exactly as you instructed):
*       wealth        : Poor (poorest+poorer) / Middle / Rich (richer+richest)
*       partner educ. : Higher / Non-higher
*       partner occup.: Not working / Agri-informal / Skilled-business / Professional
*                       ("Other" occupation is set to missing and counted in the log)
*       internet      : Never / Past-infrequent / Regular-frequent
*   - estimates store names shortened (the long names caused "invalid name").
*   - graph export now uses name(); interaction tests use merged categories,
*     with Holm adjustment for the rural-urban family.
*   - Rural = residence 2, urban = residence 1 (DHS coding).
*
* STILL VERIFY IN THE CODEBOOK: V704 codes, V743A/B/D codes (is code 3
* "respondent + other person"? is code 6 "other"?), V169C, V171A/B, V157-V159.
*==============================================================================

    display as error "WARNING: analytic sample unexpectedly small (expected about 18,794). Check the missing-value table above."

* Sequential exclusion flow (for the flowchart); most structural variables first

gen byte _keep = 1
foreach v of local flow_order {
    quietly count if _keep==1 & missing(`v')
    local lost = r(N)
    quietly replace _keep = 0 if missing(`v')
    quietly count if _keep==1
    post `fh' ("Missing: `v'") (`lost') (r(N))
}
postclose `fh'
preserve
use `flowtmp', clear
list, noobs sep(0)
export delimited using "$out/exclusion_flow.csv", replace
restore

*------------------------------------------------------------------------------
* 15. INTERACTION TESTS (merged categories; Holm within the rural-urban family)
*------------------------------------------------------------------------------
local pool "`bgA' `w3' `soc' `life' `psy'"
tempfile inttmp
postfile inth long family str40 test double F double p using `inttmp'

display as text _n "========== A15: RESIDENCE X EMPOWERMENT =========="

quietly testparm i.residence#i.marriage_timing

display as text _n "========== A18: PARTNER EDUCATION X MARRIAGE TIMING =========="
svy, subpop(sub_analytic): logistic higher_edu `pool' i.partner_edu_hi#i.marriage_timing
estimates store A18_pedu_mar
quietly testparm i.partner_edu_hi#i.marriage_timing
display as text "Partner education x marriage timing: F = " %6.2f r(F) "  p = " %6.4f r(p)
post inth (2) ("partner_edu_hi x marriage_timing") (r(F)) (r(p))

postclose inth
preserve
use `inttmp', clear
sort family p
by family: gen int rank = _n
by family: gen int m = _N
gen double holm = min(1, (m - rank + 1)*p)
by family: replace holm = max(holm, holm[_n-1]) if _n > 1
format F %8.2f
format p holm %8.4f
display as text _n "INTERACTION TESTS (family 1 = rural-urban, Holm-adjusted within family)"
list family test F p holm, noobs sep(0) abbrev(32)
export delimited using "$out/interaction_tests.csv", replace
restore
